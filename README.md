# Словокрафт — веб-версия для GitHub Pages

Статический HTML/CSS/JavaScript-порт Android-приложения «Словокрафт». **Не требуется** Node.js, Gradle, сборка, сервер или платный хостинг.

## Публикация в GitHub Pages

Рекомендованный вариант — **отдельный репозиторий** `slovokraft-web`, чтобы не мешать сборке APK в текущем репозитории `words`.

1. Создайте новый **публичный** репозиторий на GitHub (например, `slovokraft-web`).
2. Через **Add file → Upload files** загрузите в **корень** репозитория четыре файла из этого архива: `index.html`, `styles.css`, `app.js`, `game-data.json`, а также `favicon.svg` (всего пять файлов). Не загружайте сам ZIP.
3. Откройте **Settings → Pages → Build and deployment**.
4. Установите **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**. Нажмите **Save**.
5. После завершения публикации откройте `https://<ваш-логин>.github.io/slovokraft-web/`.

### Если хотите разместить в существующем репозитории `words`

Чтобы не затереть Android-проект, положите файлы в директорию `docs/`, затем в **Settings → Pages** выберите **Branch: main**, **Folder: /docs**. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/words/`.

## Содержание

- Исходные 78 слов, 16 групп, 6 цветных биомов, 20 достижений, все орфограммы и подсказки из Kotlin-проекта.
- Режимы: Верстак, Шахта памяти, Охота на мобов, Экзамен (3 сердечка), Кузница ошибок.
- XP, уровни, комбо, изумруды, алмазы, достижения, результаты экзаменов.
- Страница школьного листа со списком слов и ударениями.
- Сохранение игрового прогресса в `localStorage` **этого браузера и домена**. Между телефонами и Android-приложением прогресс **не синхронизируется**.
- Русское произношение через `speechSynthesis`, если поддерживается браузером и доступен русский голос.

## Локальная проверка

Из каталога проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Важные отличия от Android

Это самостоятельный веб-порт игровой логики и данных, **не** автоматическая трансляция Jetpack Compose. Вместо Android Canvas/3D используются адаптивные CSS-пиксельные блоки. Room заменена на localStorage. Браузерный TTS зависит от устройства. Отдельного бэкенда нет.
